# Tools

## Browser

The browser opens full screen in front of the dashboard on the panel, and anyone can watch it there or over VNC.
Its profile is kept between tasks, so sites stay logged in.
When a task that used the browser is finished, use the browser tool's `stop` action, so the panel returns to the dashboard.
Leave it open only when Aaron asks for a page to use or log in to by hand.
Never enter payment details, buy anything, or send a message from the browser.

## Home Assistant

The `home-assistant` skill reads the home's sensors and calendar and runs its services.
